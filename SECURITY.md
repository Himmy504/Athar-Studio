# Reporting security issues

For a vulnerability involving local file access, project parsing, executable invocation, downloads, or the Tauri boundary, use GitHub's **Security → Report a vulnerability** when private reporting is enabled.

If private reporting is unavailable, open an issue asking the maintainer for a private reporting channel without including exploit details, credentials, or private media. No dedicated security email or response-time commitment has been established for this pilot.

Include the app version, Windows version, reproduction steps, and expected impact. Prefer a minimal synthetic project. General bugs belong in the normal bug report form.
